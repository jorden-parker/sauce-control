## Findings considered and rejected

- Putting the request table inside `settings.db`: rejected in plan 001's design notes; two modules sharing one connection-less file invites `SQLITE_BUSY` handling for no gain.
- Keeping the JSON-lines file alongside the database: rejected; the user asked for a replacement, and two sinks drift.
- Native runtime secret stores: not selected. Docker and Podman differ in their secret-store interfaces and retention; the accepted shared mechanism delivers structured values through stdin, keeping credentials out of container configuration, command arguments and separate secret stores. See the [research](../docs/environment-files-research.md).
- `docker run --env-file`: rejected; Docker keeps the quotes of `KEY="value"` in the value, and the request was to parse the files.
- A browser upload input cannot recover reusable absolute paths. The implemented local file browser lists metadata server-side and supports multiple selections alongside editable paths; only paths are persisted, never imported values.
- Storing the Environment File list inside `RepositoryConfig`: rejected; the Compare page must accept paths before the Repository is configured, and a separate `environment-files:<repository>` key needs no read-time migration.
